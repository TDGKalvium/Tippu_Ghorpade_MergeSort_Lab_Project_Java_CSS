# MergeSort Lab — Interactive DAA Micro Project

## Project name
MergeSort Lab: Interactive Sorting Visualizer

## What it does
This project demonstrates Merge Sort, a divide-and-conquer sorting algorithm. The web page lets a user enter numbers, animate the split/compare/merge steps, and view the sorted output.

## Technologies
- HTML: page structure
- CSS (`style.css`): responsive dark dashboard styling
- JavaScript: interactive web animation and step-by-step sorting
- Java (`MergeSort.java`): command-line version of the Merge Sort algorithm

## Run the website
1. Open `index.html` in Chrome, Edge, or Firefox.
2. Enter numbers separated by commas.
3. Click **Load Array**, then **Start Animation** or **Next Step**.

No installation or internet connection is required for the website.

## Run the Java version
Install a JDK, open a terminal in this folder, then run:
`javac MergeSort.java`
`java MergeSort`
Enter whole numbers separated by spaces when prompted.
